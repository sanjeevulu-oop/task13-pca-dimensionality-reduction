# Task 13: PCA – Dimensionality Reduction

## Project Overview
This project demonstrates the use of **Principal Component Analysis (PCA)** to reduce the dimensionality of image data.  
The model performance is compared before and after applying PCA using **Logistic Regression**.

---

## Objective
- Apply PCA to reduce the number of features.
- Compare accuracy of models:
  - Without PCA
  - With PCA
- Visualize explained variance.
- Understand dimensionality reduction and its impact.

---

## Dataset
- **Dataset Used:** Scikit-learn Digits Dataset
- Contains images of handwritten digits (0–9).
- Each image is represented by multiple pixel features.

---

## Technologies Used
- Python
- Scikit-learn
- NumPy
- Pandas
- Matplotlib

---

## Project Steps
1. Load the digits dataset.
2. Split data into training and testing sets.
3. Scale the data using StandardScaler.
4. Train Logistic Regression without PCA.
5. Apply PCA with different components.
6. Plot explained variance.
7. Train Logistic Regression with PCA.
8. Compare model accuracy.
9. Visualize 2D PCA scatter plot.
